# Dual-bind :50051

**Date:** 2026-08-13

## Cause

Three Gaius devenv daemons (two on `/tmp/devenv-797b140`, one on
`$XDG_RUNTIME_DIR/devenv-797b140`) each ran `gaius-engine`. gRPC default
`SO_REUSEPORT` let two PIDs listen on `:50051`; Status was kernel lottery.

## Fix

- `grpc.so_reuseport=0` + bind==0 → `#EN.00000014.DUALBIND`
- `assert_tcp_port_free 50051` in `gaius-engine.sh`
- Stopped stale Gaius daemons 847315 / 857055 only (left signals / aegir /
  atelier / metabase)
- Reflection import no longer aborts the listen (protobuf gencode/runtime
  mismatch is a warning)

## Now

One listener (pid under `/run/user/1001/devenv-797b140`). Status body
`project=gaius` + `cognition`. lattice-ci still FAIL: reflection required
and `grpcio-reflection 1.83` needs protobuf 7.35.1 (venv is 6.33.5).
