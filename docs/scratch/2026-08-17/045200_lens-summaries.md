# LENS collection summaries

Same paradigm as Ontology / Heuristics, now for Articles, Projects, and Thoughts.

- `current/articles/summary.md` — one hop per article slug (`article.md` / `base.md`), not zk/sources/hx
- `current/projects/summary.md` — project notes at depth ≤ 2
- `current/thoughts/summary.md` — scratch notes in the ISO week, excluding `*_wWW-summary.md`

`/summary knowledge` with no collection writes all five. Thoughts creates
`current/thoughts/` if it is empty. Weekly Signals zettel is unchanged.
