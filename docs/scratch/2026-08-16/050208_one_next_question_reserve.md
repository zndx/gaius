# Compaction holds a slot, not a session

Continuous cognition-buffer compaction is readiness: make space for
**one next question** that can arrive at any hour. It is not a
conversation window and not a coding-session working set.

`NEXT_QUESTION_RESERVE_TOKENS` (65536 of 262144) stays empty on
purpose. A budget that eats that reserve is refused. Day and night
are the same problem.
