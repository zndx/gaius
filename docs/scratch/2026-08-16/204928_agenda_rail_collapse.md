# Agenda rail collapses to icons

Kumo left panels collapse to an icon strip (`Sidebar.Trigger` in the
footer). Agenda’s rail is the same shape: kind filters stay clickable
as icons; calendar and search need width, so those icons expand the
rail. `[` toggles, matching TUI left-panel. Preference in
`localStorage.gaius-agenda-rail`. Asset `0.2.9-agenda-rail`.
