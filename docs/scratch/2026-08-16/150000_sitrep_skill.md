# Web harness sitrep is MCP, not the workspace README

`/sitrep` is Gaius ThetaAgent (`theta_sitrep`). The isolated
workspace had no slash command, so Qwen listed the dir.

Each session workspace now gets `AGENTS.md` and
`.grok/commands/sitrep.md` (`/sitrep` → `gaius__theta_sitrep`).
The façade aliases `sitrep` / `theta_sitrep` to that MCP name.
