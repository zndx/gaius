# Development Notes

This section contains session notes, design explorations, and development logs organized by date.

## Structure

Notes are organized by ISO date:
```
notes/
├── 2025-11-28/
│   ├── 00_documentation_foundation.md
│   └── ...
├── 2025-11-29/
│   └── ...
└── README.md
```

Files within each date directory are prefixed with zero-padded numbers indicating creation order.

## Purpose

These notes serve as:
- **Development history**: Track decisions and their rationale
- **Design exploration**: Document alternatives considered
- **Session summaries**: Capture work done in each session
- **Future reference**: Help understand past context

## Usage

When starting a session:
1. Create today's directory if it doesn't exist
2. Create a new note with the next sequence number
3. Document objectives, work done, and outcomes

When reading notes:
- Browse by date to follow chronological development
- Search for topics across all notes
- Reference note IDs in discussions

## Note Format

Each note should include:
- **Session objective**: What we set out to do
- **Work performed**: What actually happened
- **Outcomes**: Results, decisions, artifacts created
- **Open questions**: Unresolved issues for future sessions
